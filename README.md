# 개인투심체크

미국 **지수(S&P500·나스닥)와 13개 섹터**에서 개인 투매가 어디서 나오고 있는지, **기관(큰손)이 던지는지 개인이 받는지** 한눈에 보는 대시보드예요. 위쪽 🇺🇸/🇰🇷 버튼으로 **한국 시장(외국인·기관·개인 수급)**도 같은 화면에서 봐요. 폰과 PC에서 같은 주소로 열리고, 60초마다 자동으로 새로고침돼요.

- **전체 탭:** 미국 시장 투매 지수, 섹터별 투매 지도(점수 높은 순 타일), 지수, 시장 전체 공포(VIX·풋/콜)
- **지수·섹터 탭:** 그 그룹의 투매 지수, **누가 던지고 누가 받나(기관 vs 개인)**, 지표별 설명, 구성 종목별 등락·거래량, 개인 순매수 흐름, 뉴스
- **역사 속 지금:** 지금 VIX를 리먼·코로나·관세 쇼크 같은 과거 폭락 때 최고치와 비교
- **🇰🇷 한국 탭:** 코스피·코스닥 오늘 외국인·기관·개인 순매수(장중 잠정), 11개 섹터(반도체·2차전지·자동차·바이오·금융·조선·방산·전력·인터넷·엔터·철강화학)별 큰손 매도 강도와 판정, 섹터별 종목 수급

| 그룹 | 대표 ETF | 개인 수급·거래량을 보는 종목 | 인버스 |
|---|---|---|---|
| S&P500 | SPY | SPXL | SPXS |
| 나스닥 | QQQ | TQQQ | SQQQ |
| 테크 | XLK | TECL | TECS |
| 반도체 | SOXX | SOXL | SOXS |
| 금융 | XLF | FAS | FAZ |
| 바이오 | XBI | LABU | LABD |
| 커뮤니케이션·경기소비재·헬스케어·에너지·산업재·필수소비재·유틸리티·소재·부동산 | XLC·XLY·XLV·XLE·XLI·XLP·XLU·XLB·XLRE | 같은 ETF | – |

개인이 몰리는 레버리지 ETF가 있으면 그걸로 개인 수급을 보고, 없으면 섹터 ETF 자체를 봐요. 그룹과 구성 종목은 `core/config.py`에서 바꿀 수 있어요.

- 화면: Streamlit Cloud (무료)
- 기록 수집: GitHub Actions (무료, 장중 15분마다)
- 데이터: 알파카 무료 키, CBOE, Stocktwits, FINRA 장외 공매도, FRED, Finnhub 뉴스 (모두 무료)

키 없이 실행하면 데모 데이터로 화면이 떠요.

## 화면 읽는 법

**맨 위 숫자 = 투매 지수 (0~100)**
전체 탭은 S&P500과 나스닥의 평균이고, 각 탭은 그 그룹의 점수예요. 섹터 점수에는 시장 전체 지표(VIX·풋/콜)를 넣지 않아서, **어느 섹터에서 투매가 시작됐는지** 구분돼요.

| 점수 | 상태 |
|---|---|
| 0~39 | 평온 🟢 |
| 40~69 | 경계 🟠 |
| 70~100 | 투매 🔴 |

**그 아래 한 줄 해석**은 투매 지수와 악재 뉴스 지수를 조합해서 나와요.

| 투매 | 악재 뉴스 | 해석 |
|---|---|---|
| 70 이상 | 낮음 | **뉴스 없는 투매**: 심리성 과매도일 가능성이 커요 |
| 70 이상 | 높음 | **악재 반영 투매**: 하락이 더 이어질 수 있어요 |
| 40~69 | 높음 | **악재에 흔들리는 중** |
| 40~69 | 낮음 | **투매 조짐** |
| 40 미만 | 높음 | **악재는 있는데 아직 덤덤**: 하락 초입일 수 있어요 |
| 40 미만 | 낮음 | **평온** (가격이 빠지면 평온한 조정) |

**누가 던지고 누가 받나 (기관 vs 개인)**
투매 지수와 별개로 **기관 매도 지수(0~100)**를 따로 보여줘요. 대표 ETF(SPY·QQQ·SOXX·XLK…)에서 한 건에 20만 달러 넘게 체결된 대량 거래를 기관·큰손으로 보고, 직전 체결가보다 낮게 체결되면 매도·높으면 매수로 나눠요(틱 규칙). 같은 체결 데이터로 개인(BJZZ)도 레버리지 ETF와 대표 ETF 양쪽에서 봐요.

| 기관 | 개인 | 판정 |
|---|---|---|
| 매도 | 매수 | **기관이 던지고 개인이 받는 중**: 개인 항복은 아직, 하락 초·중반에 자주 보이는 수급 |
| 매도 | 매도 | **기관·개인 같이 던지는 중**: 본격 투매 |
| 매도 | 중립 | **기관 주도 매도**: 개인이 따라 던지는지 지켜볼 구간 |
| 매수 | 매도 | **개인이 던지고 기관이 받는 중**: 항복 구간에서 자주 보이는 수급 |
| 중립 | 매도 | **개인만 던지는 중** |

최근 1시간·오늘·최근 5일을 같이 보여주고, 기관이 며칠째 매도 우위면 따로 알려줘요. 한계: 대량 체결이 전부 기관은 아니고, 틱 규칙 방향도 가끔 틀려요. 그래서 이것도 평소 대비 위치(백분위)로 점수를 매겨요.

**🇰🇷 한국 시장 읽는 법**
- 데이터: 네이버 증권 공개 데이터(키 없음). 지수 수급은 장중 잠정치, 섹터 수급은 대표 종목들의 일별 투자자 순매수(주식수 × 종가)를 더한 값이에요.
- 한국은 외국인+기관+개인+기타법인 순매수 합이 거의 0이라, '누가 팔았나'보다 **큰손(외국인+기관)이 평소보다 얼마나 세게 팔았나**를 봐요. 섹터는 종목별 최근 60거래일과 비교한 **큰손 매도 강도(0~100)**로 정렬해요.
- 판정: 큰손이 세게 팔고 개인이 받으면 '큰손이 던지고 개인이 받는 중(개인 항복은 아직)', 개인이 세게 팔고 큰손이 받으면 '개인이 던지고 큰손이 받는 중(항복 구간)'. 외국인이 최근 5일 중 4일 넘게 팔면 따로 알려줘요.
- 수집기가 한국 장중 10분마다 지수 수급을 기록해 '코스피 장중 누적 순매수' 그래프를 그려요. 지수 판정은 기록이 20거래일 쌓이기 전까지 고정 기준(코스피 큰손 ±3,000억, 코스닥 ±800억)을 써요.
- 섹터·종목은 `core/kr.py`의 `SECTORS`에서 바꿀 수 있어요.

**지표별로 보기**: 각 줄을 누르면 설명이 펼쳐져요. 막대가 길수록 공포가 큰 거예요.

| 지표 | 뜻 | 지연 | 가중치 |
|---|---|---|---|
| 개인 순매도 | 개인 주문으로 추정되는 체결 중 매도가 얼마나 많은지 (BJZZ 방식, 레버리지 ETF) | 15분 | 25 |
| 본체 ETF 개인 순매도 | 같은 방식으로 대표 ETF(SOXX 등)에서 (레버리지와 다른 그룹만) | 15분 | 10 |
| 거래량 | 오늘 거래량이 평소 같은 시각의 몇 배인지 (하락하는 날만 크게 반영) | **장중 실시간 추정** | 20 |
| 종목 전반 투매 | 구성 종목 중 2% 넘게 빠지면서 거래량이 1.5배를 넘은 종목 비율 | 실시간 추정 | 15 |
| Stocktwits 심리 | 약세 태그 비율 + 글 올라오는 속도 (S&P500·나스닥·반도체만) | 실시간 | 15 |
| 인버스 갈아타기 | 인버스 거래대금 ÷ 레버리지 거래대금 (인버스 있는 그룹만) | 15분 | 10 |
| VIX/VIX3M | 1을 넘으면 단기 패닉 (지수 그룹만) | 15분 | 10 |
| 풋/콜 비율 | 미국 주식 옵션의 하락 베팅 ÷ 상승 베팅 (지수 그룹만) | 30분 | 5 |
| 장외 공매도 비율 | FINRA가 공개하는 장외 체결 중 공매도 비율. 개인이 사면 증권사가 공매도로 대주기 때문에 **평소보다 낮을수록 개인 매도** | 하루 1번 (전일) | 5 |
| 하이일드 스프레드 | 신용 낮은 회사채 금리 − 국채 금리 (FRED, `FRED_KEY` 권장). 벌어질수록 시장 전체 공포 (지수 그룹만) | 하루 늦게 | 5 |
| 악재 뉴스 | 최근 1시간 그룹 종목 뉴스 건수와 악재 비율 (알파카 + Finnhub, 투매 점수와 별도) | 실시간 | – |

해당 없는 지표는 빠지고, 남은 지표의 가중치로 100점 환산해요.

**실시간 거래량 추정:** 알파카 무료 플랜은 전체 시장 데이터를 15분 늦게 주고, IEX 거래소 데이터만 실시간으로 줘요. IEX는 전체 거래량의 일부지만 종목별 비중이 꽤 일정해서, "오늘 IEX 거래량 ÷ (최근 20일 IEX 평균 × 이 시각까지 보통 쌓이는 비율)"로 계산하면 실제 상대 거래량과 거의 비슷하게 나와요. 개인 순매도는 거래소 밖 체결이라 IEX에 안 잡혀서 15분 지연 그대로예요.

**역사 속 지금**: VIX(1990년~)는 시대가 달라도 같은 방식이라 과거 폭락 때 최고치와 비교해요. 개인 수급은 수수료 무료화·개인 급증·0DTE 옵션 등으로 구조가 바뀌어 과거와 직접 비교하지 않아요.

점수는 각 지표가 **최근 기록 중 어디쯤인지(백분위)**로 매겨요. 2008년이나 닷컴 버블 같은 과거 사건이 아니라 **최근 약 3개월(60거래일)**이 기준이에요(VIX·하이일드 스프레드는 최근 1년, 뉴스는 최근 3일 같은 시간대). 기록이 쌓이기 전(처음 며칠)에는 고정 기준으로 매기고, 화면에 "기준치 쌓는 중"이라고 표시돼요.

> 참고 지표예요. 매수·매도 신호가 아니에요.

## 설치 (처음 한 번, 약 15분)

### 1. GitHub에 올리기
1. GitHub에서 **비공개(Private)** 저장소를 만들어요. 예: `retail-sentiment`
2. 이 폴더의 파일을 **전부** 올려요. 숨김 폴더 `.github`, `.streamlit`도 꼭 포함해야 해요.

### 2. 알파카 키 준비
알파카 → **Paper Trading(모의계좌)** 화면 → API Keys에서 Key와 Secret을 발급받아요.
실계좌 키 말고 **모의계좌 키**를 쓰세요. 데이터는 똑같이 나오고, 키가 유출돼도 돈이 나갈 일이 없어요.

### 3. 수집기 켜기 (GitHub Actions)
1. 저장소 → Settings → Secrets and variables → Actions → New repository secret
   - `ALPACA_KEY` = 알파카 Key
   - `ALPACA_SECRET` = 알파카 Secret
2. 저장소 → Actions 탭 → 왼쪽 **collect** → **Run workflow** → mode `backfill`, days `10` → 실행
   - 과거 10거래일 개인 수급(15개 종목)과 60일 풋/콜, 3일치 뉴스를 채워요. 1시간 안팎 걸려요.
   - 기준치가 더 탄탄해지길 원하면 나중에 days를 늘려 한 번 더 돌려도 돼요(이미 있는 구간은 건너뛰어요).
   - 끝나면 `data` 브랜치가 생기고 CSV 파일이 쌓여 있어요.
3. 이후로는 장중 15분마다 자동으로 돌아요.

### 4. 기록 읽기용 토큰 (비공개 저장소라서 필요)
GitHub → 프로필 → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate
- Repository access: **Only select repositories** → 이 저장소만
- Permissions → Contents: **Read-only**
- 만들어진 `github_pat_...` 값을 복사해 둬요.

### 5. Streamlit에 배포
1. https://share.streamlit.io 에서 **GitHub로 로그인**
2. Create app → 저장소 선택, Branch `main`, Main file `app.py`
3. Advanced settings → Secrets에 아래를 붙여넣고 값을 채워요.
   ```toml
   ALPACA_KEY = "..."
   ALPACA_SECRET = "..."
   GH_REPO = "내아이디/retail-sentiment"
   GH_TOKEN = "github_pat_..."
   DATA_BRANCH = "data"
   ```
4. Deploy를 누르면 `https://...streamlit.app` 주소가 생겨요.
5. 앱 Settings → Sharing에서 **나만 볼 수 있게** 설정해요. 무료는 비공개 앱이 1개까지예요.

### 6. 폰 홈 화면에 추가
- 아이폰: Safari로 열기 → 공유 → 홈 화면에 추가
- 안드로이드: Chrome으로 열기 → ⋮ → 홈 화면에 추가

- 12시간 동안 아무도 안 열면 앱이 잠들어요. 열었을 때 깨우기 버튼을 누르면 30초~1분 뒤 정상으로 돌아와요. 잠든 동안에도 수집기는 계속 기록해요.
- GitHub Actions 예약 실행은 몇 분씩 늦어질 수 있어요.
- 비공개 저장소의 Actions 무료 사용량은 월 2,000분이에요. 이 수집기는 대략 월 1,300~1,600분 정도 써요. 빠듯하면 `collect.yml`의 장중 주기를 `*/15`에서 `*/30`으로 바꾸세요. 공개 저장소는 무제한이에요(키는 Secrets에 있어서 공개돼도 안전해요).
- Stocktwits는 요청 제한이 있어서 S&P500(SPY)·나스닥(QQQ)·반도체(SOXL)만 봐요.
- Yahoo 데이터는 Streamlit 서버에서 자주 막혀서 쓰지 않아요.
- Stocktwits가 서버 접속을 막으면 그 지표만 빠지고 나머지 점수로 계산돼요.

## 내 PC에서 돌려보기
```bash
pip install -r requirements.txt
streamlit run app.py          # 키 없으면 데모
```
키를 넣으려면 `.streamlit/secrets.toml.example`을 `.streamlit/secrets.toml`로 복사해서 채우세요.
주소 뒤에 `?demo=1`을 붙이면 언제든 데모 화면을 볼 수 있어요. `?g=semi`처럼 그룹 키를 붙이면 그 탭으로 바로 열려요.

## 설정 바꾸기
`core/config.py`에서 그룹·구성 종목·한글 이름, 가중치, 경계 점수, 새로고침 간격을 바꿀 수 있어요.

## 파일 구조
```
app.py                 화면
ui.py                  디자인(HTML/CSS)
collector.py           기록 수집기 (Actions가 실행)
core/
  alpaca.py            알파카 API
  retail_flow.py       개인 매수/매도 추정 (BJZZ) + 기관 대량 체결 매수/매도 (틱 규칙)
  realtime.py          IEX 실시간 거래량 추정, 종목 전반 투매
  cboe.py              VIX, 풋/콜
  finra.py             FINRA 장외 공매도 (키 없음)
  fred.py              FRED 하이일드 스프레드 (FRED_KEY 권장)
  finnhub.py           Finnhub 뉴스 보충 (수집기만)
  history.py           역사 속 지금 (과거 폭락 VIX 비교)
  kr.py                한국 시장 외국인·기관·개인 수급 (네이버 증권)
  stocktwits.py        Stocktwits 심리
  news.py              뉴스 수치화
  scoring.py           점수·해석
  metrics.py           지표 계산
  sources.py           데이터 모으기 + 데모 데이터
  store.py             기록 읽기/쓰기
.github/workflows/collect.yml   수집 일정
tests/                 테스트 (python -m pytest -q)
키등록.cmd             Finnhub·FRED 키를 GitHub Secrets에 넣는 더블클릭 파일 (tools/set-keys.ps1)
```
